# Simple Interest Calculator

A simple bash/python script to calculate simple interest given principal, annual rate of interest, and time period in years.

## Formula
$$\text{Simple Interest} = \frac{P \times T \times R}{100}$$

## Inputs
- `P`: Principal amount
- `T`: Time period in years
- `R`: Annual rate of interest

## Output
- `Simple Interest`: The calculated interest amount
